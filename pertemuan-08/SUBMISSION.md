# Pengumpulan Mini Project — Pertemuan 08

## Yang Dikumpulkan

1. **Folder project lengkap** (tanpa `.venv`): kode + `requirements.txt` + README project.
2. **README project** wajib memuat:
   - Nama anggota + pembagian tugas,
   - Tema yang dipilih + **2 konsep (atau lebih) yang digabung**,
   - Cara setup & menjalankan, contoh output (screenshot boleh).
3. **Demo** di depan asisten (langsung di kelas atau video ≤ 5 menit, sesuai opsi timeline).

## Format & Cara Kumpul

- Satu folder/zip bernama: `P08_Kelompok-XX` (atau `P08_NIM_Nama` jika individu).
- Kumpulkan lewat kanal yang ditentukan asisten.
- **Batas waktu:** diumumkan di kelas (opsi in-class: akhir sesi; opsi take-home: sebelum jadwal demo).

## Checklist Penilaian

- [ ] Program jalan tanpa error saat demo
- [ ] Minimal 2 konsep benar-benar terintegrasi (bukan tempelan)
- [ ] Prompt dirancang sadar (system message / few-shot / format output)
- [ ] Tiap anggota bisa menjelaskan bagian kodenya saat ditanya
- [ ] README project lengkap — orang lain bisa menjalankan ulang tanpa bantuan
- [ ] Demo rapi + jujur soal keterbatasan aplikasi (ingat prinsip UX pertemuan-05)
- [ ] Bonus: ada test pytest / fitur ekstra (potong riwayat, penanganan error, tool tambahan)

## Aturan Umum

- Kolaborasi antar anggota kelompok wajib; menyalin dari kelompok lain = diskualifikasi.
- Boleh pakai AI assistant untuk membantu koding, TAPI kalian harus paham setiap baris — akan diuji saat demo.
- Kesulitan teknis? Konsultasi ke asisten SEBELUM hari demo.
